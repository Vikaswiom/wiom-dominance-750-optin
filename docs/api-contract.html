Behaviour Notes for FE

  • All JSON fields use snake_case naming.
  • All timestamps are ISO 8601 UTC (e.g. 2026-08-17T10:30:01Z).
  • consent_timestamp is set server-side — do not send it in the request.
  • consent_choice accepts exactly two values: OPTED_IN or NOT_NOW.
  • A CSP who previously chose NOT_NOW can later call POST again with OPTED_IN — the row gets updated.
  • An already OPTED_IN CSP receives an idempotent 200 with already_enrolled: true. No error is thrown.
  • An OPTED_IN CSP cannot revert to NOT_NOW via this API (no self-serve opt-out).
  • The enrolled field in the GET status response is a convenience boolean: true when consent_choice == OPTED_IN.
  • Config values (payout_amount_paise, validity_window_days) are runtime-configurable by Product. Always fetch fresh.
